# Portfolio2DS-AMS

Atividades das matérias durante o 2° Ano do meu curso na ETEC Zona Leste, DS/AMS. Matérias estas que são: Banco de Dados I, Programação Web II, Sistemas Embarcados, Programação e Aplicativo Mobile I, Desenvolvimento de Sistemas e Análise e Projeto de Sistemas.

## Projetos acadêmicos incorporados

- [DadosSalario](Programação%20Web%20II/DadosSalario/) — exercício de cálculo salarial em PHP, HTML e CSS.

Alguns projetos acadêmicos que antes estavam em repositórios separados foram incorporados a este portfólio para centralizar as atividades do curso. Os demais trabalhos e materiais continuam organizados por disciplina.

- [PHP-Exercicios](Programação%20Web%20II/PHP-Exercicios/) — exercícios de PHP, JavaScript e CSS.
- [CRUD-Financeiro-PW2](Programação%20Web%20II/CRUD-Financeiro-PW2/) — sistema CRUD financeiro em PHP/PDO com MySQL.

- [AppSQLite](Programação%20e%20Aplicativo%20Mobile%20I/AppSQLite/) — aplicativo Android em Kotlin com autenticação e persistência local usando SQLite.

- [ETEC2-Site](Programação%20Web%20II/ETEC2-Site/) — site institucional acadêmico com HTML, CSS, JavaScript e PHP.
