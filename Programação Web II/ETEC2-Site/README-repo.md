# ETEC2 — Site institucional

Projeto acadêmico de um site para a ETEC Zona Leste, com páginas em HTML/CSS, JavaScript e funcionalidades em PHP.

## Executar localmente

1. Use PHP com um servidor local (por exemplo, XAMPP) e coloque os arquivos em uma pasta servida pelo Apache.
2. Configure as variáveis de ambiente `ETEC_USER` e `ETEC_PASSWORD` no ambiente em que o PHP roda.
3. Acesse `index.html` pelo servidor local.

O login foi ajustado nesta cópia para **não manter usuário e senha fixos no código**. Sem configurar as variáveis de ambiente, o login não aceitará credenciais. Não use credenciais de demonstração em ambientes públicos.

> Projeto acadêmico: revise a validação de entradas, a configuração de sessão e o armazenamento de credenciais antes de qualquer implantação real.
